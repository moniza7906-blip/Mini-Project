Varanasi Heritage Website

About the Project

The Varanasi Heritage Website is a mini-project designed to showcase the rich cultural heritage, historical landmarks, temples, ghats, and tourism attractions of Varanasi, India. The aim is to make information about the city's heritage accessible through a simple and user-friendly website.

Features

- Information about Varanasi's heritage and culture
- Dedicated pages for heritage sites and tourism
- Images and visual content
- Interactive website navigation
- Cultural and tourism information in one place

Technologies Used

- HTML5
- CSS3
- JavaScript

Project Structure

The repository contains HTML pages, CSS stylesheets, and JavaScript files used to build the website.

How to Run

1. Open or download this repository.
2. Locate the "index.html" file.
3. Open "index.html" in a web browser to explore the website.

Future Improvements

- Add more heritage locations and cultural information.
- Improve mobile responsiveness and accessibility.
- Integrate interactive maps and additional tourism resources.

Author

Developed as a college mini-project on the heritage and tourism of Varanasi.
